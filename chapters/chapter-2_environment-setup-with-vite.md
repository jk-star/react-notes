## Vite kya hai?

- Vite ek modern development tool hai jo React project ko bahut fast start aur run karta hai.
- Pehle log CRA (Create React App) use karte the.
- Ab almost sab Vite use karte hain.

## CRA vs Vite

| CRA              | Vite        |
| ---------------- | ----------- |
| Slow             | Very Fast   |
| Start time zyada | Instant     |
| Bundle heavy     | Lightweight |
| Old              | Modern      |
| Development slow | Fast        |
