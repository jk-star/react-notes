## React ki Features

| Feature          | Simple Meaning                                   |
| ---------------- | ------------------------------------------------ |
| Component Based  | Chhote-chhote reusable parts me UI banana        |
| Fast Updates     | Sirf changed part update hota hai                |
| Reusable         | Ek component ko baar-baar use kar sakte hain     |
| Easy Maintenance | Code organized rehta hai                         |
| Large Community  | Bahut documentation aur tutorials available hain |
